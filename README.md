# Chinmay Deo — academic portfolio

This is a no-build, multi-page website for GitHub Pages. Open `index.html` to preview it.

## Personalise it

- Replace bracketed text (`[like this]`) in each HTML page.
- Replace the `#` destinations for LinkedIn, GitHub, ORCID, project links, and paper links.
- Add `images/chinmay-portrait.jpg` for the Bio hero portrait.
- Add `images/project-01.jpg` through `project-03.jpg` for Projects.
- Add `images/publication-01.jpg` through `publication-03.jpg` for Research.

Before you add images, clean built-in placeholder artwork appears automatically—there are no broken image icons. When an image with the matching filename is added, it replaces the placeholder immediately.

## Features

- Bio, Research, Projects, Experience, Leadership, Hobbies, and Awards pages.
- Light/dark theme toggle, remembered by the browser.
- Typing hero greeting and scroll-assembled headings, with no-JavaScript content fallback.
- Clickable project and research-cover cards.

## Publish with GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload everything inside this folder to the repository root.
3. In GitHub **Settings → Pages**, deploy the `main` branch from `/(root)`.
4. Visit `https://YOUR-USERNAME.github.io` when the deployment completes.
